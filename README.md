# BF6 Combat Tracker

An unofficial installable web app for looking up Battlefield 6 player statistics through the third-party GameTools.Network endpoint.

## Install on Android
Open the GitHub Pages HTTPS site in Chrome, then use **⋮ → Install app** (or **Add to Home screen**).

## Notes
- Not affiliated with EA or Battlefield.
- No EA password is requested.
- Live stats depend on third-party API availability, supported platform identifiers, rate limits and browser CORS policy.
- Automatic refresh only runs while the app is open.
- Offline caching stores the app shell, not live player statistics.
